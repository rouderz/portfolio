**Gift it** (built by the ShopIt team) is a social shopping app on iOS where friends discover products, build wishlists
and send each other gifts. It runs on Shopify for the catalog and checkout, Convex for the backend, and Expo for the
mobile app. The codebase is private, so this page is a tour of the product through screenshots.

## My role

I worked on the team as a mobile and full-stack engineer for about a year, with 150+ commits across the app and the
backend. I owned features from first prototype to production, wrote the tests around them, and kept the docs in sync.

## What I built

- **Save for later in the cart.** A device-local saved list, made safe for account changes, partial adds and retries with
  write-ahead recovery so a failed move can never lose or duplicate an item.
- **Back-in-stock alerts.** A "notify me when it's back" flow on out-of-stock products, from the Convex schedule to the
  mobile UI.
- **Replacement gift suggestions** after a gift order is cancelled, so the sender can still surprise their friend.
- **Verified product reviews**, with a "Helpful" action and animated feedback.
- **Friends feed redesign**, later moved into the bottom navigation.
- **A price-first product page**, with tags, badges and a clearer layout.
- **Discovery that fails gracefully**, with real loading and error states on every surface.
- **Public wishlist gifting**, and international phone number matching for contact sync.

## Engineering beyond features

- Fixed an image upload ownership hole in the backend and added a 13+ birthday safeguard.
- Upgraded the app to Expo SDK 57 for the new iOS scene life cycle.
- Added CI guards (mobile API signature drift, Convex deploy gated on tests and typecheck) and targeted unit tests for
  pure business logic.
- Wrote documentation pages for the team, kept honest by a CI check that fails when covered code changes without a docs update.

## Stack

React Native (Expo, React 19), TypeScript, Convex, Clerk, Stripe, Shopify, Next.js (merchant dashboard), Turborepo and
Bun, Biome, Jest.
