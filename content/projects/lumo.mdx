## What it is

**Lumo** is a native macOS app (Swift 6, SwiftUI + AppKit) that lives alongside the MacBook notch.
This is an **example project**: replace this text with your own.

## What it includes

- Permission approvals from the notch, always with an explicit click.
- Characters drawn in code with `Canvas`.
- No telemetry: network calls only go to services you configure.
